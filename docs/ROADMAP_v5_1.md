# BarAI Desktop v5.1

Versione di rifinitura del modulo Controllo Prezzi.

## Novità

- Filtri avanzati per ricerca, categoria, fornitore e variazione prezzo.
- Soglia aumento/ribasso configurabile.
- Evidenziazione righe con aumento sopra soglia.
- Dettaglio prodotto con ultime righe di acquisto.
- Esportazione CSV della vista corrente.
- Mappatura rapida dei prodotti non mappati.
- Suggerimenti semplici per categoria e unità di misura.

## Nota

Questa versione non cambia la posizione del database locale. Continua a usare lo stesso `barai.sqlite` dentro la cartella dati dell'app.
