# BarAI Desktop - Roadmap v1

## Obiettivo
Creare una sola app desktop installabile su Mac, con database SQLite locale, moduli separati e sincronizzazione futura con Google Sheet/Drive.

## v1 inclusa in questo pacchetto
- Struttura Tauri + React
- Sidebar BarAI
- Dashboard base
- Scadenziario base funzionante
- Database SQLite locale `barai.sqlite`
- Tabelle iniziali per Admin, Scadenziario, Prezzi e Food Cost
- Dati demo per testare velocità e flusso
